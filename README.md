## 🌟 Features

- **🌍 Multi-Language Support:** Fully localized in 6 languages:
  - Türkçe (TR)
  - English (EN)
  - Français (FR)
  - 中文 (ZH)
  - Русский (RU)
  - العربية (AR)
- **🌤️ Real-Time & Forecast Data:** Current temperature, apparent temperature (feels like), wind speed, humidity, and a 5-day forecast.
- **🎨 Custom Terminal UI:** Built with `rich` for gorgeous panels, grids, tables, and integrated custom ASCII art visuals.
- **⚡ Zero API Key Required:** Powered seamlessly by the free Open-Meteo API.
